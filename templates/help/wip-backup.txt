Push unfinished work to your own private backup repo (off this disk).

The remote is wip.backup_url from config.yml. While it is empty, nothing is
pushed and every repo lands under "Failed" in the report (git has no target).

Per repo under your configured work roots (paths.work_roots; one run per shared
git dir):
  - every local branch with commits on no remote  -> refs/heads/<repo-key>/<branch>
  - newest wip-snapshot ref per worktree          -> refs/heads/wip/<worktree-key>
Never touches worktrees, branches or the real remotes. Hooks are NOT bypassed
(--no-verify is banned): a repo with a pre-push hook is skipped and listed;
wip.backup_hook_off names origin fragments this rule may bypass. A ref whose
new commits fail the secret scan (wip.secret_gate; never a password on git,
private repos included) is NOT pushed and is listed as skipped. Repos whose
git dir exceeds wip.backup_max_repo_mb and shallow clones are skipped whole.

Restore: git fetch '<wip.backup_url>' '<repo-key>/<branch>:<branch>'
Usage: wip-backup [--dry-run] [--quiet]
