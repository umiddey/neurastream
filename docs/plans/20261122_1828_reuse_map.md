# Reuse map: an opt-in Graphify code map that every new plan must cite before it can be saved
Plan file: /home/ukd/projects/neurastream/docs/plans/20261122_1828_reuse_map.md
Worktree: /home/ukd/Work/neurastream-reuse-map
Planner: PlanNeurastreamGraphify
Branch: feat/reuse-map
Summary: Opt in once (setup or `neurastream reuse on`) and neurastream installs Graphify, maps your repos and keeps the map fresh; from then on a new plan cannot be saved until its `## Reuse` cites the existing code the map found. Off by default; off changes nothing.

## Goal
- Owner (2026-11-22, via Main): "Stop AI agents from building parallel systems instead of reusing existing code … when an agent writes a PLAN, it is FORCED (mechanically blocked, not instructed) to look at the relevant existing code, using a repo map from Graphify. Enforcement BEFORE or AT plan write time." Neurastream owns Graphify end to end; the user never types `graphify`.
- Done =
  1. `reuse_map:` config (enabled false). Off: no `graphify`/`uv`/`pipx` process, no `graphify-out/` read, no plan error or refusal changes.
  2. `neurastream setup` offers it; `neurastream reuse on|off [--purge]|status [--json]|map` does the same later. On = install pinned `graphifyy==0.9.100`, per chosen repo `extract . --code-only` + `graphify hook install`, config written last. `uninstall` runs `reuse off`; `doctor` reports health and flags any other graphify version.
  3. At plan write the EXISTING plan-edit gate (Main and delegated-planner branches) refuses a new plan body whose `## Reuse` lacks the map line for its terms, quotes a cited line that is not the file's text at that line, cites fewer than `min_cited` matched files, or says "none to reuse" while any of its ≥ 3 terms hits.
  4. In `planner delegated`, the existing spawn gate refuses a planner brief without its plan's map line.
  5. Every Graphify failure while enabled refuses with a one-line fix command, never a silent pass; a stale graph is updated before every query.
