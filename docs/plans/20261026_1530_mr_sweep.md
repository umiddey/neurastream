## Goal
- Owner correction 2026-10-26: MR !206 (dispositions) was opened under his account, then the session died before writing its Progress bullet; the next rollover rebuilt the same work as a duplicate. Plans said "one MR left to do" while GitLab already had it open.
- Deterministic fix: a sweep that lists open MRs per repo and diffs them against open plans. MR state is read from the forge (source of truth), never from handoff memory.
- Rules: only Main pushes/merges; nothing today records "MR opened/pending" in plans automatically; push commands cannot reveal MR intent. So: read the forge at defined moments.

## Design
- Repo set: every distinct repo root of the plans listed in /home/ukd/.omp/agent/INDEX.md (dirname of each plan file, walked up to the dir containing .git).
- Forge detection from the origin remote URL: `gitlab` host → `glab mr list`, `github` host → `gh pr list`. Anything else → skipped with a one-line note.
- Degradation (open-source requirement): CLI missing, not authenticated, no network, or command fails → that repo is skipped, sweep still exits 0. The sweep never becomes a hard dependency on glab/gh.
- Tracked = an MR is considered tracked when its `!N` (or `#N` for GitHub) OR its source branch name appears in ANY open plan of that repo. An open plan may also carry `MR !N: ignored (<reason>)` which counts as tracked (escape valve for known-stale MRs; plan text only, no new files).
- Output: one line per untracked MR: `UNTRACKED MR !206 pm <repo> (branch) — no open plan mentions it`.
- Reuse: the plan enumerator in src/core/queue/lib.ts (activePlans, :255-257) already loads every plan with paths; main-start's non-blocking child helper (:37-56) is the pattern for CLI calls.

## Forbidden
- Never write to plans automatically (the sweep reports; Main writes the bullets).
- Never call gateforge/witness/pin. Never edit INDEX.md from the sweep.
- No new long-running services, no polling loops; the sweep runs only where main-start/queue-check already run.
