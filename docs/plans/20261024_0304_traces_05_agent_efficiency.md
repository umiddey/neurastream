## Background
Trace format (read by Main 2026-10-24 in ~/.omp/agent/sessions/-projects/*.jsonl): one JSON object per line; type in session, model_change (model, resolvedModelIsFallback), message, model_usage, custom, compaction. message.message.role = user | assistant | toolResult. Assistant messages carry model, provider, api, responseId, stopReason, usage{input,output,cacheRead,cacheWrite,totalTokens,cost}, content[] with {type:"toolCall", id, name, arguments, intent}. toolResult carries toolCallId, toolName, isError, content. Subagent sessions sit one level deeper (session dir), named <spawn name>.jsonl.
