  1. In plain `omp`, no neurastream hook runs: no queue summary, no guards, no edit cap, no stop-continuation, no Discord posts, no inbox poll, no `/main-rollover`. The Main rules are not in its system prompt.

  3. A child harness started from inside a Main session (bash `omp -p …`, subagents) inherits the env, so it stays guarded. Nothing escapes the guards by running `omp` from a tool.
