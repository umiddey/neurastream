# Plans close themselves; the index only grows (append-only, read-only file)
Worktree: /home/ukd/Work/neurastream-forced-close
Branch: fix/forced-close
Summary: A script closes a plan as soon as its code is on main and its done check passes, so Main can no longer leave finished plans open. The plan list (INDEX.md) can only grow: only queue-close/queue-cancel remove a line, the file is read-only on disk, and tests can never reach it.

- Matching Main's reply text (phrases): the owner ruled it out; the lock reads plan state only.
- A guard that refuses spawns ON the plan that blocks: fix work for that plan must stay spawnable.
