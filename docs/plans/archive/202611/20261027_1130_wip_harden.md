Summary: Unsaved work is snapshotted every hour from the folders or repos you choose, and backed up nightly ONLY to a repo that is verifiably private. Any failure pings you, and one command sets it all up or restores a save.

- Done = (1) `wip.roots` lists any number of folders OR single repos, managed by `neurastream wip add|remove|list`; (2) one broken repo never stops the run; (3) wip-backup pushes only after the target is confirmed private, refuses and alerts otherwise (public, internal, unknown, check failed), and checks it on every nightly run even with nothing to push; (4) old snapshots are pruned; (5) failures and stale runs alert via notify + incident + main-start; (6) `neurastream wip on|off` installs/removes the timers (systemd on Linux, launchd on macOS) and `init` offers it; (7) `neurastream wip restore` lists and restores a save; (8) a repo with its own pre-push hook is still skipped unless its origin is listed in `wip.backup_hook_off` (hooks are never bypassed by default), and the skip says how to opt in.

- Never weaken the secret scan: every pushed ref still goes through `wip.secret_gate scan` first; exit ≠ 0 = not pushed.
- Never change the user's worktrees, index or branches during a snapshot (the temp-index approach stays). `wip restore` refuses a dirty worktree unless it snapshots it first.
- Host-neutral: src/core names no harness (omp/opencode/codex/claude/cursor); docs/adapter.md.
- Tests never touch the real home, network, GitHub, systemd or launchd: inject the runner, the visibility checker and the service manager.
