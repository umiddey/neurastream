# WIP backup you can trust: your folders, private-only, loud when it breaks
Worktree: /home/ukd/Work/neurastream-wip-harden
Branch: feat/wip-harden
Summary: Unsaved work is snapshotted every hour from the folders or repos you choose, and backed up nightly ONLY to a repo that is verifiably private. Any failure pings you, and one command sets it all up or restores a save.

- Never change the user's worktrees, index or branches during a snapshot (the temp-index approach stays). `wip restore` refuses a dirty worktree unless it snapshots it first.
